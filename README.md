# ระบบฐานข้อมูล MOU วิทยาลัยพณิชยการบางนา

PHP 8.0+ (PDO) · MySQL/MariaDB · Bootstrap 5 · DataTables · Chart.js · SweetAlert2 — ไม่ต้องใช้ Composer และไม่ต้องต่ออินเทอร์เน็ต (ไลบรารี/ฟอนต์อยู่ใน `assets/vendor/`)

## มีอะไรใหม่ใน v2
รูปภาพประกอบรายละเอียด MOU (อัลบั้ม + Lightbox), โหมดมืด/สว่าง, Design System ใหม่, Animations, Loading overlay, ดู/ซ่อนรหัสผ่าน — **อัปเกรดจากเวอร์ชันเดิม ดูขั้นตอนที่ `docs/UPGRADE-v2.md`** (ต้องนำเข้า `database/migration_v2_images.sql`)

## ติดตั้ง (XAMPP)
1. คัดลอกโฟลเดอร์ `mou-system` ไปไว้ที่ `C:\xampp\htdocs\` (ต้องได้ `htdocs\mou-system\config\...` ไม่ซ้อนสองชั้น)
2. เปิด Apache + MySQL; ตรวจว่าเปิดส่วนขยาย `pdo_mysql`, `fileinfo`, `mbstring`, `zip` (ใช้ส่งออก XLSX) ใน php.ini
3. phpMyAdmin → Import → `database/schema.sql` (สร้างฐาน `mou_bangna`, ตารางทั้งหมด, บัญชี `admin`, สาขาวิชา, ประเภทความร่วมมือ, ค่าตั้งค่า — นำเข้าซ้ำได้ ไม่ลบข้อมูลเดิม)
   - ต้องการข้อมูลตัวอย่างไว้ทดลอง: นำเข้า `database/sample_data.sql` ต่อ (**ห้ามใช้บนระบบจริง** — เป็นหน่วยงาน/MOU สมมติที่จะขึ้นหน้าเว็บสาธารณะ)
4. แก้ `config/config.php`: `DB_USER`, `DB_PASS`, `RATE_SALT` (ค่าสุ่มเฉพาะเครื่อง) — `BASE_URL_CONFIG` ไม่ต้องแก้ถ้าใช้ในเครือข่ายภายใน (ระบบปรับตาม IP/ชื่อเครื่องที่เปิดให้เอง); ใส่ชื่อโดเมนเมื่อใช้โดเมนจริง
5. เปิด `http://localhost/mou-system/`
6. หลังบ้าน `/admin/login.php` → `admin` / `Admin@1234` — ระบบ**บังคับให้ตั้งรหัสผ่านใหม่ทันที**ก่อนใช้เมนูอื่น; บัญชีตัวอย่าง `staff01`, `viewer01` ที่ยังใช้รหัสเริ่มต้นจะเข้าใช้ไม่ได้จนกว่า admin จะตั้งรหัสใหม่ให้ที่เมนูผู้ใช้งาน
7. ถ้าลิงก์สวย (`/mou/5`) ใช้ไม่ได้: ตั้ง `USE_PRETTY_URLS` เป็น `false` ใน config หรือแก้ `RewriteBase` ใน `.htaccess`

## ขึ้น Production
- `APP_ENV_MODE` ค่าเริ่มต้น `'auto'` (เครื่องเซิร์ฟเวอร์เองเห็นรายละเอียด error, เครื่องอื่นเห็นหน้าแจ้งข้อผิดพลาดทั่วไป) — โฮสติ้งจริง/หลัง reverse proxy ให้ตั้งเป็น `'production'`
- สร้างผู้ใช้ฐานข้อมูลเฉพาะระบบ (ไม่ใช้ `root`) พร้อมรหัสผ่าน, ใส่ชื่อโดเมนจริงใน `BASE_URL_CONFIG`, แก้ `RewriteBase` ใน `.htaccess` ถ้าเปลี่ยนชื่อโฟลเดอร์, ใช้ HTTPS
- ลบข้อมูลตัวอย่างออก (ลบ MOU → หน้ารายการ → "ที่ลบแล้ว" → ลบถาวร)
- `uploads/` ต้องเขียนได้ และ Apache ต้องอ่าน `.htaccess` (`AllowOverride All`); ถ้าใช้ Nginx ต้องตั้งกฎห้ามเข้า `uploads/`, `config/`, `includes/`, `models/`, `database/` เอง
- สำรองข้อมูล: หน้า "ตั้งค่าเว็บ" → **ดาวน์โหลดไฟล์สำรองข้อมูล** (zip: `database.sql` + `uploads/`) แดชบอร์ดจะเตือน admin เมื่อไม่ได้สำรองเกิน 7 วัน; ต้องการสำรองอัตโนมัติให้ตั้ง Task Scheduler รัน `tools\backup.bat` (แก้ค่าต้นไฟล์ให้ตรงเครื่อง)
- แจ้งเตือน MOU ใกล้หมดอายุ: ระบบทำเองวันละครั้งเมื่อมีคนเปิดเว็บครั้งแรกของวัน (ขึ้นที่รูประฆังหลังบ้าน + ส่งอีเมลสรุปถ้าตั้ง "อีเมลรับแจ้งเตือน" และ PHP ส่งอีเมลได้); ต้องการให้ตรงเวลาแม้ไม่มีคนเปิดเว็บ ให้ตั้ง Task Scheduler รัน `C:\xampp\php\php.exe C:\xampp\htdocs\mou-system\cron\notify_expiring.php`
- อีเมล (แจ้งเตือน, ตอบกลับผู้เสนอ) ใช้ `mail()` ของ PHP — ต้องตั้ง SMTP/sendmail ใน `php.ini` ก่อน; ถ้ายังไม่ตั้ง ระบบจะแจ้งว่าส่งไม่ได้และให้ใช้ปุ่ม "เปิดโปรแกรมอีเมล" แทน

## โครงสร้าง
config/ ค่าตั้งค่า · includes/ db, functions, auth, layout_*, xlsx · models/ คิวรี MOU · public/ หน้าสาธารณะ + download.php ·
admin/ หลังบ้าน · assets/ css, js, vendor (ไลบรารี+ฟอนต์) · uploads/ ไฟล์อัปโหลด · database/ schema.sql, sample_data.sql · cron/ งานตามเวลา · tools/ สคริปต์สำรองข้อมูล · docs/ ERD

## สิทธิ์
admin = ทุกอย่าง (รวมลบ MOU ถาวร) · staff = MOU/ต่ออายุ/หน่วยงาน/สาขา/ข่าว/ข้อเสนอ/รายงาน · viewer = Dashboard + รายงาน + เปิดดูรายละเอียด MOU แบบอ่านอย่างเดียว (ไม่เห็นงบประมาณ/หมายเหตุภายใน — เปลี่ยนได้ที่ `VIEWER_SEES_INTERNAL` ใน config)

## หมายเหตุ
- สถานะ MOU คำนวณจากวันที่สิ้นสุดวันละครั้ง (เมื่อมีคนเปิดเว็บครั้งแรกของวัน หรือเมื่อแก้ไข/ต่ออายุ) — ใกล้หมดอายุ = ภายในจำนวนวันที่ตั้งในหน้าตั้งค่า ค่าเริ่มต้น 90
- ลบ MOU เป็นการซ่อน (กู้คืนได้ที่หน้ารายการ → "ที่ลบแล้ว"); ลบถาวรทำได้เฉพาะ admin และจะลบไฟล์แนบ/รูปทั้งหมด
- Activity Log ค้นหา/แบ่งหน้าฝั่งเซิร์ฟเวอร์ และลบรายการที่เก่ากว่า `LOG_RETENTION_DAYS` (ค่าเริ่มต้น 365 วัน, 0 = เก็บตลอด) อัตโนมัติ
- ไฟล์แนบ `.doc`/`.docx` ตรวจจากโครงสร้างภายในไฟล์จริง (รองรับไฟล์จาก Google Docs/LibreOffice)
- Login ผิด 5 ครั้งล็อก 15 นาที นับแยกตาม "ชื่อผู้ใช้ + IP" (และเพดานรวม 30 ครั้งต่อ IP); เปลี่ยนรหัสผ่านแล้วเซสชันอื่นของบัญชีนั้นถูกบังคับออก
- ฉบับร่าง/ยกเลิก/ไม่เผยแพร่ ไม่แสดงสาธารณะ; งบประมาณ ผู้ติดต่อ เบอร์ อีเมล หมายเหตุ ไม่แสดงสาธารณะเสมอ
- รายงาน PDF: กด “PDF / พิมพ์” แล้วเลือก “บันทึกเป็น PDF” (ฟอนต์ไทยครบ ไม่ต้องติดตั้งไลบรารี)
- reCAPTCHA/Turnstile: ใส่ค่าใน `CAPTCHA_*` ของ config

## แนวทางต่อยอด
1. แจ้งเตือนผ่าน LINE: ต่อยอดจาก `cron/notify_expiring.php` ส่งผ่าน LINE Messaging API; ส่งอีเมลตอบกลับผู้เสนออัตโนมัติด้วย PHPMailer + SMTP
2. QR Code ลิงก์ MOU: สร้าง QR ชี้ `route('mou_detail', id)` ด้วย phpqrcode แล้วพิมพ์ลงเอกสาร
3. Import จาก Excel: `admin/import.php` รับ CSV/XLSX → ตรวจ → พรีวิว → บันทึกด้วย transaction
4. PDF ฝั่งเซิร์ฟเวอร์ (mPDF + Sarabun), 2FA สำหรับ admin, ติดตามสถานะข้อเสนอด้วยเลขอ้างอิง
