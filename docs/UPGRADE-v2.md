## ขั้นที่ 1 — สำรองข้อมูลก่อน (สำคัญ)
1. phpMyAdmin → ฐาน `mou_bangna` → แท็บ **Export** → Go (ได้ไฟล์ .sql)
2. คัดลอกโฟลเดอร์ `htdocs/mou-system` ทั้งก้อนเก็บไว้ เช่น `mou-system-backup`

## ขั้นที่ 2 — สร้างตารางรูปภาพ (ฐานข้อมูล)
ไฟล์ใหม่: `database/migration_v2_images.sql`

- **ระบบที่ติดตั้งแล้ว** → phpMyAdmin → เลือก `mou_bangna` → **Import** → เลือกไฟล์นี้ → Go (ไม่ลบข้อมูลเดิม)
- **ติดตั้งใหม่** → นำเข้า `database/schema.sql` อย่างเดียวพอ (เพิ่มตาราง `mou_images` ไว้แล้ว)

ตาราง `mou_images`: `mou_id`, `stored_name` (ชื่อไฟล์สุ่ม), `caption`, `width/height/size`, `is_cover`, `sort_order` — ลบ MOU ถาวรแล้วแถวรูปจะถูกลบตาม (ON DELETE CASCADE)

> ถ้าลืมขั้นนี้ เว็บยังทำงานได้ตามปกติ (ระบบตรวจว่ามีตารางหรือไม่) แต่จะแสดงกล่องเตือนให้รัน migration ในส่วนรูปภาพ

## ขั้นที่ 3 — คัดลอกไฟล์ใหม่ทับของเดิม
แตก zip แล้วคัดลอกทับ `htdocs/mou-system` **ยกเว้น** `config/config.php` ถ้าแก้รหัสฐานข้อมูลไว้แล้ว — ให้เปิดไฟล์เดิมแล้วเพิ่มบล็อกนี้แทน (วางก่อนส่วน Rate limit):

```php
// ---------- รูปภาพประกอบรายละเอียด MOU / กิจกรรม (v2) ----------
define('IMAGE_MIMES', ['image/jpeg' => 'jpg', 'image/png' => 'png', 'image/webp' => 'webp']);
define('MAX_MOU_IMAGE_SIZE', 5 * 1024 * 1024);   // 5MB ต่อรูป
define('MAX_MOU_IMAGES', 30);                     // สูงสุดกี่รูปต่อ MOU
define('IMAGE_MAX_DIMENSION', 1920);              // ย่อด้านยาวสุดเหลือกี่พิกเซล
```

ตรวจว่ามีโฟลเดอร์ `uploads/mou_images/` และ `uploads/activities/` และ Apache เขียนไฟล์ได้

## ขั้นที่ 4 — ตั้งค่า PHP (php.ini) ให้อัปโหลดหลายรูปได้
XAMPP → Config → php.ini แล้วตรวจค่า (แก้แล้ว Restart Apache):

```ini
extension=gd            ; ใช้ย่อรูป/หมุนรูปตาม EXIF (ไม่มีก็ใช้ได้ แต่ไฟล์จะใหญ่)
extension=exif          ; (ไม่บังคับ) หมุนรูปจากมือถือให้ตั้งตรง
upload_max_filesize = 10M
post_max_size = 64M     ; ต้องมากกว่า (จำนวนรูปที่ส่งพร้อมกัน × ขนาดรูป)
max_file_uploads = 30
```

## ขั้นที่ 5 — Design System (`assets/css/style.css`)
ไฟล์เขียนใหม่ทั้งหมด แบ่งเป็น 8 ส่วนตามคอมเมนต์หัวไฟล์ หัวใจคือ **token** บน `:root`:

```css
:root {
  --c-primary: #0b2e6b;  --c-surface: #fff;  --c-text: #172033;   /* สีตามความหมาย */
  --grad-brand: linear-gradient(135deg, #071d45, #0b2e6b 55%, #1c4fa8);
  --sp-1: .25rem … --sp-9: 4rem;                                  /* Spacing */
  --r-xs: 6px; --r-sm: 10px; --r-md: 14px; --r-lg: 20px; --r-xl: 28px;  /* Radius */
  --sh-xs … --sh-xl, --sh-glow;                                    /* Shadow 5 ระดับ + เรืองแสง */
}
[data-bs-theme="dark"] { --c-surface: #0f1a2e; --c-text: #e5ebf6; … }  /* โหมดมืดแค่สลับค่า */
```

ทุก component ใช้ `var(--…)` จึง **ไม่ต้องเขียน CSS โหมดมืดแยกทีละชิ้น** — อยากเปลี่ยนสีทั้งเว็บแก้ที่ token จุดเดียว
และ map เข้าตัวแปรของ Bootstrap (`--bs-body-bg`, `--bs-border-color` …) ทำให้ฟอร์ม ตาราง dropdown ของ Bootstrap เปลี่ยนตามธีมเอง

คลาสที่ใช้บ่อย:

| คลาส | ใช้ทำอะไร |
|---|---|
| `.fade-up` `.fade-in` `.scale-in` + `.delay-1..4` | เคลื่อนไหวตอนเข้า |
| `.stagger` (ใส่ที่ตัวแม่) | ลูกทุกตัวค่อยๆ เข้าทีละตัว (JS ใส่ `--i` ให้) · `.stagger.scale` = แบบขยาย |
| `.reveal` | โผล่เมื่อเลื่อนมาถึง |
| `.hover-lift` | ลอยขึ้นเมื่อชี้ |
| `.chip` `.chip-primary` `.chip-gold` | ป้ายเล็กโค้งมน |
| `.surface` `.detail-box` `.panel` | การ์ดพื้นฐาน |
| `.shapes` + `<span class="s1..s6">` | รูปทรงลอย |
| `.bounce-icon` | ไอคอนเด้ง (เด้งแรงขึ้นเมื่อชี้) |

ผู้ใช้ที่ตั้ง "ลดการเคลื่อนไหว" ในระบบปฏิบัติการ จะปิดแอนิเมชันให้อัตโนมัติ (`prefers-reduced-motion`)

`assets/css/admin.css` — Sidebar แบ่งกลุ่มเมนู, Topbar โปร่งแสง (blur), การ์ดสถิติ, หน้า Login แบบกระจก

## ขั้นที่ 6 — ชิ้นส่วน UI กลาง (`includes/ui.php` ไฟล์ใหม่)
| ฟังก์ชัน | หน้าที่ |
|---|---|
| `theme_boot_script()` | วางใน `<head>` ก่อน CSS — อ่านธีมที่เคยเลือก แล้วตั้ง `data-bs-theme` ก่อนหน้าแสดง (กันจอขาวแวบ) |
| `ui_head_assets()` / `ui_scripts()` | โหลดฟอนต์ Bootstrap Icons DataTables SweetAlert2 Chart.js + `style.css`/`app.js` พร้อม `?v=` |
| `theme_toggle_button()` | ปุ่มพระจันทร์/พระอาทิตย์ |
| `page_loader()` | Loading overlay (มีตัวกันค้าง: ซ่อนเองใน 6 วินาทีแม้ JS เสีย) |
| `media_url($dir, $file)` | ลิงก์รูปผ่าน `public/image.php` |
| `panel_title()` `empty_state()` `initial_of()` | หัวแผงพร้อมไอคอน, ข้อความเมื่อไม่มีข้อมูล, อักษรย่อ |

> เมื่อแก้ CSS/JS ในอนาคต ให้เพิ่มเลข `ASSET_VER` ใน `ui.php` เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่

## ขั้นที่ 7 — JavaScript กลาง (`assets/js/app.js`)
ไม่ต้องเขียนโค้ดเพิ่มในแต่ละหน้า — แค่ใส่ attribute:

| ใส่ใน HTML | ผล |
|---|---|
| `data-theme-toggle` | ปุ่มสลับธีม (ส่ง event `mou:themechange` ให้กราฟเปลี่ยนสี) |
| `<input type="password">` | ได้ปุ่ม 👁 ดู/ซ่อนรหัสผ่าน + เตือน Caps Lock อัตโนมัติ (ใส่ `data-no-toggle` ถ้าไม่ต้องการ) |
| `<a href="รูปใหญ่" data-lightbox="ชื่อกลุ่ม" data-caption="…">` | เปิด Lightbox, รูปกลุ่มเดียวกันกดถัดไปได้ |
| `<label class="dropzone" data-dropzone data-max="30" data-max-mb="5"><input type="file" multiple>` | กล่องลากวาง + พรีวิว + ลบออกก่อนส่ง + ตรวจชนิด/ขนาด |
| `data-no-loader` (บนลิงก์/ฟอร์ม) | ไม่แสดง Loading overlay (ลิงก์ดาวน์โหลด/ส่งออก Excel ถูกยกเว้นให้แล้ว) |
| `data-confirm="ข้อความ"` | ถามยืนยันก่อน (ของเดิม) |

## ขั้นที่ 8 — ระบบรูปภาพ (ฝั่งเซิร์ฟเวอร์)
1. **`includes/functions.php`** เพิ่ม `normalize_files()` (แปลง `$_FILES['images']` หลายไฟล์), `optimize_image()` (หมุนตาม EXIF → ย่อ ≤1920px → บีบอัด → ลบ EXIF เช่นพิกัด GPS), `save_images()` (ใช้ `save_upload()` เดิมที่ตรวจ MIME จากเนื้อไฟล์จริง + ชื่อไฟล์สุ่ม)
2. **`models/mou_model.php`** เพิ่ม `has_mou_images()`, `mou_images_of()`, `mou_images_add()` (รูปแรกเป็นปกอัตโนมัติ, จำกัดจำนวน) และ `mou_search()` คืน `cover_image`, `image_count` เพิ่ม
3. **`admin/mou_actions.php`** เพิ่ม action: `upload_images`, `delete_image` (ลบปก → รูปถัดไปเป็นปกแทน), `set_cover`, `save_images` (คำบรรยาย+ลำดับ), และ `add_activity` รับรูปได้ — ทุก action ผ่าน CSRF + สิทธิ์ `mou` + viewer แก้ไม่ได้ เหมือนเดิม
4. **`public/image.php`** รองรับโฟลเดอร์ `mou_images`, `activities` — รูปของ MOU ที่ **ยังไม่เผยแพร่/ฉบับร่าง/ถูกลบ** คนทั่วไปเปิดไม่ได้ (404) เห็นได้เฉพาะเจ้าหน้าที่ที่ login, รูปสาธารณะส่ง cache 30 วัน + ETag
5. `uploads/.htaccess` เดิมห้ามเข้าโฟลเดอร์ตรงอยู่แล้ว รูปจึงผ่าน PHP เท่านั้น

## วิธีใช้งาน (เจ้าหน้าที่)
1. **เพิ่มรูปตอนสร้าง/แก้ MOU**: หลังบ้าน → ข้อตกลง MOU → เพิ่ม/แก้ไข → เลื่อนลงที่ "รูปภาพประกอบรายละเอียด" → ลากรูปมาวาง → บันทึก
2. **จัดการรูป**: เปิดหน้ารายละเอียด MOU → แผง "รูปภาพประกอบรายละเอียด" → พิมพ์คำบรรยาย/ตัวเลขลำดับ → "บันทึกคำบรรยาย/ลำดับ" · กด ⭐ เพื่อตั้งเป็นภาพปก · 🗑 เพื่อลบ
3. **รูปกิจกรรม**: แผง "กิจกรรมภายใต้ MOU" → กรอกกิจกรรม + เลือกรูป → เพิ่มกิจกรรม
4. รูปจะแสดงบนเว็บสาธารณะเมื่อ MOU **เผยแพร่** และสถานะไม่ใช่ฉบับร่าง/ยกเลิก
